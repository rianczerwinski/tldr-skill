# Lineage and boundaries

## Purpose and reuse posture

Response shaping controls how information is selected, organized, and paced. Domain attunement controls which prior knowledge an explanation assumes. These dimensions compose independently: an expert may need brevity, a non-specialist may request depth, and an exhaustive plan may need spatial organization rather than deletion. Keep the established `i-have-adhd` handle for compatibility, with a broader discovery description and a continuing ADHD preset. Keep `tee-up` responsible for preparing preference decisions rather than moving decision research into a presentation skill.

## Primary precedents

- [W3C cognitive accessibility guidance](https://www.w3.org/TR/coga-usable/) separates short blocks of text (§4.4.5), summaries (§4.4.8), and processes that avoid reliance on memory (§4.7). Component prior art: distinguish selecting content from organizing it and supporting action. This is supplemental web guidance, not a clinical theory or proof of one optimal chat format.
- [Kalyuga, expertise reversal](https://www.cambridge.org/core/books/abs/cambridge-handbook-of-multimedia-learning/expertise-reversal-principle-in-multimedia-learning/BFAF296ADA85C944355A12DDFD50ACF8) describes how guidance useful for novices can hinder more knowledgeable learners. Component prior art: keep domain knowledge independent of requests for brevity. The conversational application is a design inference.
- [Writing Clearly and Concisely, actual skill source](https://github.com/softaworks/agent-toolkit/blob/main/skills/writing-clearly-and-concisely/SKILL.md) supplies sentence-level economy. Component precedent rather than a replacement: it does not supply this local-vs-continuing invocation contract or the separation between reorganization and compression.
- [Agent Skills specification](https://agentskills.io/specification) places capability and trigger terms in discoverable descriptions and supports progressively loaded references. Enabler, not a guarantee that any provider will select or obey a skill.

## Design and evidence boundary

The separation of comprehension from presentation follows the task's observed failure modes and the component precedents. The precise triggers and session duration are interaction contracts, not discoveries about ADHD. The absence of a word quota is deliberate: neither a length limit nor a keyword hook can validate preservation of a causal relationship. Use paired behavioral evaluation for that judgment, with the user's real experience as the practical oracle. A fully merged communication skill becomes preferable only if observed activation failures persist despite clear composition; split presentation operations into separate skills only if they repeatedly interfere.
