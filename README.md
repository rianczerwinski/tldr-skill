# tldr

Reduce reading effort while keeping the substance and reasoning intact. The [skill](SKILL.md) handles concise rewrites, clearer organization, and one-at-a-time pacing independently.

Use `tldr` or `$tldr` for a concise rewrite of the current answer. Ask for `tldr mode` or “keep replies short” for a continuing preference. “Wall of text; keep every point” changes layout without deleting content. “One step at a time” paces user actions or decisions while authorized agent work continues.

The familiar “adhd” and “I have ADHD” phrases retain their continuing-preset behavior. The installed skill name is `tldr`; `i-have-adhd` remains a conversational alias. A request for detail always controls the depth of that answer.

See [evaluation.md](evaluation.md) for behavioral cases and proof limits, [antipatterns.md](antipatterns.md) for paired examples, and [lineage.md](lineage.md) for prior art and scope. Provider metadata lives in `agents/`.
